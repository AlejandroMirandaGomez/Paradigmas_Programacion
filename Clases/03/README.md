## Objetivos
Tener una noción preliminar conceptual y práctica sobre los siguientes temas:
1. Lenguajes Humanos versus Formales Artificiales
2. Facetas declarativa/operativa (datos vs control), sintaxis/semántica.
3. Pirámide de Abstracción. Expresividad.  
4. Estructura General de un Compilador: 
    * Parsing (análisis sintáctico)
    * Typer (análisis semántico estático)
    * Optimizer
    * Code Generator
5. Transpilación versus Compilación.
6. Análisis de Código
    * Disciplina estática versus dinámica. 
    * Duck Typing, Inferencia, Polimorfismo, Genericidad
    * Análisis de Fuente (linters, estilizadores) 
7. La IA y la programación.    
8. Prácticas con Java,JS/TS usando entornos minimalistas
